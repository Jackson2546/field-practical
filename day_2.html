DAY 2

About Domain Name:

A domain name is the easy-to-remember name of a website on the internet. It is the address you type into a web browser to visit a website. For example: google.com wikipedia.org juco.ac.tz Instead of remembering a website's numerical IP address (such as 142.250.190.14).

About Sub Domain Name:

is a part added before the main domain name to create a separate section or website. Example: sims.juco.ac.tz

About Web Hosting:

Web hosting is a service that stores your website's files on a computer (server) connected to the internet.
